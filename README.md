# 잿빛 성역 · Ashen Sanctum

마흔 명의 영웅이 칼, 마법, 총으로 맞붙는 **1인칭 다크 판타지 아레나**예요. 브라우저에서 바로 돌아가고, PC와 모바일 모두 지원해요.

## 플레이

GitHub Pages 주소로 들어가면 바로 시작돼요. 로컬에서 돌리려면 저장소 폴더에서 정적 서버를 켜면 돼요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 흐름

1. **홈**: 조수 영웅이 제단에 서 있어요. 출정, 모집, 영웅, 임무, 상점, 소식으로 이동해요.
2. **출정**: 모드를 카드로 골라요.
   - 캠페인: 3장 24스테이지. 스테이지마다 별 3개 조건과 첫 클리어 보상이 있어요.
   - 보스 레이드: AI 아군 둘과 잿빛 군주를 4분 안에 쓰러뜨려요. 보통 · 어려움 · 악몽.
   - 랭크전: 이기면 30점, 지면 18점. 잿빛부터 성역까지 등급, 매달 새 시즌.
   - AI 대전: 영웅, 전장, 난이도를 고른 뒤 3대3 섬멸전을 해요.
   - 5대5 난전: 열 명이 넓은 전장에서 맞붙어요. 온라인 방에서도 3대3 · 5대5를 고를 수 있어요.
   - 심연 토벌: AI 아군 둘과 끝없는 웨이브를 막는 생존 모드. 5웨이브마다 우두머리.
   - 온라인: 방을 만들거나 다섯 글자 코드로 참가한 뒤, 방 안에서 영웅을 골라요.
   - 훈련장: 허수아비로 스킬을 연습해요.
3. **보상**: AI 대전은 승리 260, 패배 100 결정에 처치와 라운드 승리마다 더 받아요. 매일 처음 접속하면 결정 500과 정수 20. 레벨이 오르면 결정 300과 정수 15.
4. **육성**: 정수로 레벨, 인장으로 정예 단계(레벨 상한 20 · 30 · 40), 기술서로 기술 레벨을 올려요. 온라인을 뺀 모든 모드에 적용돼요.
5. **모집**: 처음에는 5명만 쓸 수 있고, 나머지는 모집으로 얻어요.
   - 1회 600 결정 또는 허가증 1장
   - 확률: ★6 1%, ★5 5%, ★4 45%, 잔불 49%
   - ★6 없이 70회가 넘으면 매번 ★6 확률이 2%씩 올라요.
   - 매일 바뀌는 오늘의 모집에서는 ★6 1명과 ★5 2명의 확률이 올라가요.
   - 중복 영웅은 잠재가 오르고, 잔불 증표로 바뀌어요.
6. **상점**: 잔불 증표로 원하는 영웅이나 허가증을 교환해요.

## 속성

모든 영웅은 여섯 속성 중 하나를 가져요. 공격이 맞으면 속성 효과가 붙고, 같은 팀에 같은 속성이 2명 이상이면 공명 보너스가 생겨요.

| 속성 | 적중 효과 | 공명 |
|---|---|---|
| 화염 | 3초 동안 불태움 | 피해 +6% |
| 빙결 | 둔화, 5번 쌓이면 0.7초 빙결 | 최대 체력 +8% |
| 뇌전 | 25% 확률로 주변 적에게 번개 | 이동 속도 +6% |
| 암흑 | 흡혈 8%, 체력 35% 이하 적에게 피해 +15% | 흡혈 +4% |
| 신성 | 주는 치유 +20%, 가장 다친 아군 치유 | 받는 치유 +10% |
| 자연 | 중독, 받는 치유 -30% | 초당 체력 2 회복 |

## 모드와 성장

- 캠페인, 보스 레이드, 랭크전, AI 대전, 5대5 난전, 심연 토벌, 온라인, 훈련장
- 영웅마다 고유 패시브와 자원 게이지(혈기, 열기, 영혼 등)
- 임무: 일일 4개, 주간 4개, 업적 14개
- 모집: 봉인 낙하, 카드 넘김, ★5 이상과 새 영웅의 전신 등장 연출

총 영웅은 탄창과 재장전이 있고, 근접 영웅은 3연격 콤보(베기, 반대로 베기, 내려찍기)와 검기 궤적이 있어요.

영웅마다 고유한 기술이 있어요. 몇 가지 예:

- 니르: 조준한 적의 등 뒤로 순간이동
- 시라: 적과 자리를 맞바꾸고 기절시킴
- 에리스: 아군 곁으로 순간이동하며 치유
- 제노: 2.5초 전 위치로 되돌아가며 회복
- 아우라: 창을 던지고 꽂힌 곳으로 번개처럼 이동
- 하르크: 적을 꿰뚫고 손으로 돌아오는 도끼
- 잭: 세 번 튕긴 뒤 터지는 폭탄
- 리안: 1.4초 뒤 터지는 거울 분신을 남김
- 루나, 라젤, 이리스, 베일라: 질주한 길에 각자 다른 지대(빙판, 감전, 꽃잎 칼날, 피 안개)를 남김

스킬을 쓰면 발밑에 마법진이 떠오르고, 궁극기는 빛기둥과 함께 모두의 화면 위쪽에 누가 무엇을 썼는지 알림이 떠요.

## 알아 두면 좋은 점

- 진행 상황(보유 영웅, 재화)은 브라우저에 저장돼요. 다른 사람과 공유되지 않아요.
- 업데이트해도 저장 데이터는 지워지거나 줄어들지 않아요. 백업 칸과 브라우저 내부 DB에 이중으로 저장하고, 설정에서 저장 코드를 복사해 다른 기기로 옮길 수 있어요.
- 온라인 연결은 PeerJS 공개 중계 서버로 서로를 찾은 뒤 직접 연결해요. 회사나 학교처럼 막힌 네트워크에서는 연결이 안 될 수 있어요.
- 모바일에서는 화면을 한 번 누르면 전체 화면으로 바뀌어요. 메뉴는 위아래로 끌어서 넘기고, 전투는 가로 화면으로 해 주세요. 아이폰 사파리는 웹페이지 전체 화면을 지원하지 않아서, 공유 버튼에서 "홈 화면에 추가"로 설치하면 주소창 없이 전체 화면으로 열려요.
