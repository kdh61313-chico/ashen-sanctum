# 잿빛 성역 · Ashen Sanctum

마흔 명의 영웅이 칼, 마법, 총으로 맞붙는 **1인칭 다크 판타지 아레나**예요. 브라우저에서 바로 돌아가고, PC와 모바일 모두 지원해요.

## 플레이

GitHub Pages 주소로 들어가면 바로 시작돼요. 로컬에서 돌리려면 저장소 폴더에서 정적 서버를 켜면 돼요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 흐름

1. **홈**: 조수 영웅이 제단에 서 있어요. 전투, 모집, 영웅, 상점으로 이동해요.
2. **전투**
   - AI 대전: 영웅, 전장, 난이도를 고른 뒤 3대3 섬멸전을 해요.
   - 온라인 팀전: 방을 만들거나 다섯 글자 코드로 참가한 뒤, 방 안에서 영웅을 골라요.
   - 훈련장: 허수아비로 스킬을 연습해요.
3. **보상**: 경기가 끝나면 잿빛 결정과 경험치를 받아요. 레벨이 오르면 결정과 모집 허가증을 더 받고, 매일 처음 접속하면 보급도 받아요.
4. **모집**: 처음에는 5명(발로크, 이그나, 셀레네, 모르, 그레이브)만 쓸 수 있고, 나머지 35명은 모집으로 얻어요.
   - 1회 600 결정 또는 허가증 1장
   - 확률: ★6 2%, ★5 8%, ★4 50%, 잔불 40%
   - ★6 없이 50회가 넘으면 매번 ★6 확률이 2%씩 올라요. 처음 10회 안에 ★5 이상 1명이 보장돼요.
   - 매일 바뀌는 오늘의 모집에서는 ★6 1명과 ★5 2명의 확률이 올라가요.
   - 중복 영웅은 잠재가 오르고, 잔불 증표로 바뀌어요.
5. **상점**: 잔불 증표로 원하는 영웅이나 허가증을 교환해요.

## 구조

외부 3D 모델, 이미지, 사운드 파일 없이 전부 코드로 만들었어요.

```
index.html, css/        화면과 UI (style.css 전투/선택, meta.css 홈/모집/상점/모바일)
js/heroes.js, heroes2.js  영웅 40명과 스킬 데이터, 등급
js/profile.js           재화, 레벨, 모집(천장), 상점 (localStorage 저장)
js/sim.js               전투 시뮬레이션 (방장 판정, 탄창, 위험 지형)
js/ai.js                봇 AI와 길찾기
js/map.js               전장 4개 배치
js/world.js             전장 그래픽 (용암/물 셰이더, 소품)
js/models.js, models2.js  영웅 모델, 무기, 애니메이션 (달리기/옆걸음/점프/착지/콤보)
js/viewmodel.js         1인칭 손과 무기 (반동, 재장전, 검기)
js/fx.js                파티클, 투사체, 범위 효과, 궤적, 총구 화염
js/game.js              한 판의 진행, HUD, 네트워크 동기화, 터치 입력
js/net.js               PeerJS 연결
js/main.js              홈, 선택, 모집, 상점, 로비, 입력, 렌더 루프
vendor/                 three.js r170, PeerJS 1.5
```

## 알아 두면 좋은 점

- 진행 상황(보유 영웅, 재화)은 브라우저에 저장돼요. 다른 기기나 브라우저와는 공유되지 않아요.
- 온라인 연결은 PeerJS 공개 중계 서버로 서로를 찾은 뒤 직접 연결해요. 회사나 학교처럼 막힌 네트워크에서는 연결이 안 될 수 있어요.
- 모바일은 가로 화면으로 해 주세요. 그래픽이 버거우면 설정에서 낮음으로 바꿔 보세요.
