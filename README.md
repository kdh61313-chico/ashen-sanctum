# 잿빛 성역 · Ashen Sanctum

스무 명의 영웅이 총 대신 칼과 마법으로 맞붙는 **1인칭 다크 판타지 아레나**예요. 브라우저에서 바로 돌아가고, 설치나 서버가 필요 없어요.

## 플레이

GitHub Pages 주소로 들어가면 바로 시작돼요. 로컬에서 돌리려면 저장소 폴더에서 정적 서버를 켜면 돼요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html`을 파일로 바로 열면 모듈 로딩이 막히니까 꼭 서버로 열어 주세요.

## 모드

- **훈련장**: 허수아비를 상대로 스킬을 연습해요. 궁극기가 계속 충전돼요.
- **AI 대전**: 3대3 라운드제 섬멸전. 부활 없이 상대 셋을 모두 쓰러뜨리면 라운드 승리, 먼저 3라운드를 가져가면 이겨요. 난이도는 쉬움, 보통, 어려움.
- **온라인 팀전**: 방을 만들면 다섯 글자 방 코드가 나와요. 친구가 코드를 입력하면 브라우저끼리 직접 연결돼요(WebRTC, PeerJS). 최대 6명이고, 빈 자리는 AI로 채울 수 있어요. 방장이 게임을 돌리기 때문에 방장이 나가면 게임이 끝나요.

## 구조

외부 3D 모델이나 이미지, 사운드 파일 없이 전부 코드로 만들었어요.

```
index.html          화면 구성
css/style.css       UI
js/heroes.js        영웅 20명과 스킬 데이터
js/sim.js           전투 시뮬레이션 (방장 기준으로 판정)
js/ai.js            봇 AI와 길찾기
js/physics.js       이동, 충돌, 레이캐스트
js/map.js           경기장 배치
js/models.js        로우폴리 영웅 모델과 애니메이션
js/world.js         경기장 그래픽
js/fx.js            파티클, 투사체, 스킬 범위 이펙트
js/viewmodel.js     1인칭 손과 무기
js/stage.js         영웅 선택 화면의 제단
js/game.js          한 판의 진행, HUD, 네트워크 동기화
js/net.js           PeerJS 연결
js/audio.js         Web Audio 효과음 합성
js/icons.js         스킬 아이콘
js/main.js          메뉴, 로비, 입력, 렌더 루프
vendor/             three.js r170, PeerJS 1.5
```

영웅을 추가하거나 수치를 바꾸려면 `js/heroes.js`만 고치면 돼요. 스킬은 `melee`, `proj`, `beam`, `dash`, `blink`, `leap`, `launch`, `glide`, `grapple`, `zone`, `aoe`, `buff`, `trap` 같은 종류를 조합해서 만들어요.

## 알아 두면 좋은 점

- 온라인 연결은 PeerJS 공개 중계 서버로 서로를 찾은 뒤 직접 연결해요. 회사나 학교처럼 막힌 네트워크에서는 연결이 안 될 수 있어요.
- 그래픽이 버거우면 설정에서 그래픽을 낮음으로 바꿔 보세요.
